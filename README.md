# Dom Pedro Tech

Desenvolvimento de sites personalizados, modernos e responsivos para empresas e negócios.

## Sobre o projeto

Este projeto é o site institucional da Dom Pedro Tech, desenvolvido para apresentar os serviços de desenvolvimento web, manutenção e suporte oferecidos pela empresa.

O site foi desenvolvido com foco em uma experiência moderna, responsiva e adaptada para diferentes dispositivos.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Git
- GitHub
- GitHub Pages

## Funcionalidades

- Design responsivo
- Interface moderna
- Animações e efeitos interativos
- Apresentação dos serviços
- Serviço de manutenção e suporte
- Processo de desenvolvimento
- Área de contato
